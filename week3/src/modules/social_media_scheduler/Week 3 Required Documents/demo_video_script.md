# Demo Video Script: AI Social Media Scheduler

**Developer & Presenter:** Ali Ammar Haider  
**Module:** AI Social Media Scheduler & Caption Generator  
**Target Duration:** 3 Minutes  

---

## 🎬 Scene 1: Introduction (0:00 - 0:45)
- **Visual:** Camera on presenter or screen showing the main SafeX Group 54 Streamlit Dashboard.
- **Narrative / Dialogue:**
  > *"Hello everyone! I am Ali Ammar Haider, and today I am excited to demonstrate my Week 3 individual module for the SafeX Solutions Summer Internship: The AI-Powered Social Media Scheduler & Caption Generator.*
  >
  > *Our target company is LearnHub Academy, an online tutoring platform. The goal of this agent is to solve a major marketing bottleneck: the time-consuming process of creating, formatting, and scheduling platform-specific educational content. Let's see it in action!"*

---

## 💻 Scene 2: Streamlit Dashboard Walkthrough (0:45 - 1:45)
- **Visual:** Screen recording of the Streamlit UI. Click on "AI Social Media Scheduler & Caption Generator". Configure the Tutoring Platform Name, Audience, and select platforms. Click the "Generate & Audit 7-Day Campaign" button.
- **Narrative / Dialogue:**
  > *"Here is our interactive dashboard. In the campaign configurations panel, we can define the platform name—in this case, LearnHub Academy—our target audience, like university students, and the desired tone of voice. We can select target social networks, such as LinkedIn, Instagram, and X.*
  >
  > *Once we click 'Generate', the engine instantly builds a complete 7-day social campaign. At the top, we see a health dashboard displaying total scheduled posts, platforms covered, and a real-time character limit check. We can navigate through the day-by-day tabs from Monday to Sunday. Each tab showcases a custom-crafted caption, hashtags, suggested posting times, and an AI image prompt matching the topic.*
  >
  > *If I edit a caption to be too long, the system dynamically alerts me that it exceeds the platform's limit. This ensures we never push corrupted or truncated text to our channels. We can export this entire edited calendar in CSV or JSON formats."*

---

## 🛠️ Scene 3: API Proposal & Code Verification (1:45 - 2:30)
- **Visual:** Scroll down to the "API Integration & Automation Proposal" section. Click on the "Social API Integrations" tab and select different SDK dropdowns. Switch to the Mermaid architecture diagram.
- **Narrative / Dialogue:**
  > *"Because this is an automation proposal, I have integrated a developer playground. It shows the exact Python SDK scripts required to publish to LinkedIn, Instagram Graph, and Twitter APIs. The JSON Payload tab displays the structured payload that gets pushed to the queue, while the Architecture tab shows a Mermaid flowchart detailing the database and Celery worker pipeline.*
  >
  > *To verify our codebase stability, I wrote automated unit tests. Running 'python -m pytest tests/' executes our test suite, verifying character constraints, tone variation, and calendar structure, returning a 100% success rate."*

## 🏁 Scene 4: Conclusion (2:30 - 3:00)
- **Visual:** Camera back on presenter or showing the project case study markdown.
- **Narrative / Dialogue:**
  > *"This module provides online tutoring platforms with a robust, zero-latency content generator and a clear technical blueprint for end-to-end posting automation. Thank you so much for your time!"*
